Annotated design decisions

The dashboard has one job: let leadership decide in ten minutes whether the transformation is ahead of, on or behind plan, and why. Every element below either answers that question or names what must happen next.

A

Overall signal, top right

The verdict is the largest colored element and is read first. The headline states the verdict in words ("behind plan at the Run gate") and the sentence names the two causes, so the "why" arrives with the color. Rule: green if every phase is on track; amber if any phase is at risk or a not-yet-started phase has a readiness item off track; red only if an in-progress phase is off track. Run has not started, so its red item escalates to a decision (D2) rather than turning the whole program red.

B

Phase track with the gate marked

A three-stop timeline shows where the program sits in Crawl, Walk and Run, and an amber diamond marks the gate decision. This ties the dashboard to Member A's roadmap and explains why this quarter matters: it is the gate review.

C

One column per phase, worst status wins

Each phase shows only its two or three most important metrics. Phase status equals its worst metric, so a single problem cannot be averaged away. The current phase (Walk) has a heavier border so the eye lands there after the verdict.

D

Bullet charts instead of gauges or bars

Each metric uses a bullet chart: the dark bar is the current value, the vertical tick is the target, and the grey bands are the off track, at risk and on track zones. It shows actual against target and the threshold bands in a strip 16 pixels tall, where a gauge would need several times the space. Better is always to the right, so the scale is reversed for the "lower is better" access-time metric (M5).

E

Status never relies on color alone

Every pill pairs color with a symbol and a word (✓ on track, ! at risk, ✕ off track, ○ not started), so the page still works printed in greyscale or for color-blind readers. The trend line ("from 63%") shows direction since last quarter.

F

Decisions sit on the page, not in an appendix

Each decision names the RACI decision it falls under, its Accountable role from Member B's RACI, the metric it clears and when it is due. A leadership team that sees a red item also sees the decision that fixes it. Decision content belongs to Member B; this layout is Member C's.

G

Organizational change is measured, not assumed

M8 tracks whether the operating roles Member A says Run requires (named in Member B's RACI as the Eno Product Lead and the Slingshot GM) are actually staffed. It carries an "org change" tag and is the only off track item, which shows that the main risk is people rather than technology.
